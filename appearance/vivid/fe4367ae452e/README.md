# 汽水

> 玫红配薄荷，圆角拉满，像一罐刚开的气泡水。

| | |
| --- | --- |
| 作者 | waterfish |
| 分类 | 色彩 |

| 写法 | 简单写法（键值对） |
| 适配 | 浅色为主 |

## 改了什么

| 键 / 手段 | 值 | 为什么 |

| `主色` | `#FF4D8D` | 玫红，按钮和选中态都很跳 |
| `副色` | `#00C2A8` | 薄荷，子菜单高亮条和页面淡彩 |
| `圆角` | `20` | 大圆角，卡片接近胶囊 |

## 安装

1. 打开水鱼文集 → 设置 → 外观 → 自定义主题
2. 把 [`fe4367ae452e.js`](./fe4367ae452e.js) 下载下来（右键另存为，或者从本页下方复制）
3. 点「选择 .js 主题文件」上传，列表里出现卡片即生效

```js
// 汽水 —— 玫红 + 薄荷
主色: #FF4D8D
副色: #00C2A8
底色: #FFFFFF
圆角: 20
```

## 备注

两种高饱和撞色放在一起容易吵，所以底色留在纯白，让它们只出现在局部。
