# 湖心纸

> 湖蓝压在微冷的米白上，看一整天眼睛不发干。

| | |
| --- | --- |
| 作者 | waterfish |
| 分类 | 推荐 |
| 哈希 | `0131d5208589` |
| 写法 | 简单写法（键值对） |
| 适配 | 浅色为主 |

## 改了什么

| 键 / 手段 | 值 | 为什么 |

| `主色` | `#1F6C9F` | 链接、图标、选中态统一成湖蓝，和「纸墨」同一支颜色，只是更沉一点 |
| `底色` | `#F4F7F9` | 纸面从纯白退到一点点冷灰，屏幕亮度低的时候不发刺 |
| `圆角` | `14` | 卡片边缘软一点，但没圆成药丸 |

## 安装

1. 打开水鱼文集 → 设置 → 外观 → 自定义主题
2. 把 [`0131d5208589.js`](./0131d5208589.js) 下载下来（右键另存为，或者从本页下方复制）
3. 点「选择 .js 主题文件」上传，列表里出现卡片即生效

```js
// 湖心纸 —— 湖蓝的强调色，微冷的米白纸面
// 只写想改的三项，字体、字号、其余配色都沿用「纸墨」
主色: #1F6C9F
底色: #F4F7F9
圆角: 14
```

## 备注

浅色模式是最舒服的状态。深色模式下它仍然能用，但没有专门调过对比度，介意的话配「夜航」。
