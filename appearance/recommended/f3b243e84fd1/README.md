## 改了什么

| 键 / 手段 | 值 | 为什么 |

| `主色` | `#A63D2F` | 朱砂，用在链接和选中态上，整页只有一个重音 |
| `圆角` | `6` | 几乎是直角，卡片之间靠留白分开，不靠阴影 |

## 安装

1. 打开水鱼文集 → 设置 → 外观 → 自定义主题
2. 把 [`f3b243e84fd1.js`](./f3b243e84fd1.js) 下载下来（右键另存为，或者从本页下方复制）
3. 点「选择 .js 主题文件」上传，列表里出现卡片即生效

```js
// 素笺 —— 白纸 + 一点朱砂
主色: #A63D2F
底色: #FDFDFB
圆角: 6
```

## 备注

适合喜欢纸感但嫌米色发黄的人。深色模式下朱砂会偏暗，能看清但不够亮。
