# 墨黑

> 真正的黑，字是灰白的，除了文字什么都没有。

| | |
| --- | --- |
| 作者 | waterfish |
| 分类 | 深色 |
| 哈希 | `67baec35456a` |
| 写法 | 简单写法（键值对） |
| 适配 | 深色为主 |

## 改了什么

| 键 / 手段 | 值 | 为什么 |

| `底色` | `#0E0E10` | 接近纯黑，OLED 屏上省电 |
| `文字` | `#D6D6DA` | 不纯白，避免高对比造成的边缘光晕 |
| `主色` | `#C9C9CE` | 强调色也是灰，靠位置和粗细区分 |

## 安装

1. 打开水鱼文集 → 设置 → 外观 → 自定义主题
2. 把 [`67baec35456a.js`](./67baec35456a.js) 下载下来（右键另存为，或者从本页下方复制）
3. 点「选择 .js 主题文件」上传，列表里出现卡片即生效

```js
// 墨黑 —— 近乎纯黑，字用灰白
主色: #C9C9CE
底色: #0E0E10
文字: #D6D6DA
圆角: 8
```

## 备注

如果你用的是 OLED 屏，这套在黑底内容区几乎不发光。缺点是没有色彩提示，扫描性差一点。
