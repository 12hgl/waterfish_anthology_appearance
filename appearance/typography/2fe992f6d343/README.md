# 等宽笔记

> 所有字都用等宽，读起来像在看自己写的 README。

## 改了什么

| 键 / 手段 | 值 | 为什么 |

| `字体` | `mono` | 正文、标题、按钮统一等宽 |
| `圆角` | `8` | 等宽字配小圆角更像编辑器 |

## 安装

1. 打开水鱼文集 → 设置 → 外观 → 自定义主题
2. 把 [`2fe992f6d343.js`](./2fe992f6d343.js) 下载下来（右键另存为，或者从本页下方复制）
3. 点「选择 .js 主题文件」上传，列表里出现卡片即生效

```js
// 等宽笔记 —— 全部换成等宽字体
字体: mono
圆角: 8
```

## 备注

等宽汉字在多数系统里其实不是真等宽（中文本来就全角），主要变化在数字和英文上。
