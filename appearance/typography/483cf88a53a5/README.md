# 圆体轻松

> 圆体正文，字距稍微放开，读起来没那么正经。

## 改了什么

| 键 / 手段 | 值 | 为什么 |

| `字体` | `round` | 内置的圆体字体栈 |
| `主色` | `#7C5CFF` | 紫调强调色，跟圆体的气质搭 |

## 安装

1. 打开水鱼文集 → 设置 → 外观 → 自定义主题
2. 把 [`483cf88a53a5.js`](./483cf88a53a5.js) 下载下来（右键另存为，或者从本页下方复制）
3. 点「选择 .js 主题文件」上传，列表里出现卡片即生效

```js
// 圆体轻松 —— 圆体 + 紫色强调
字体: round
主色: #7C5CFF
圆角: 16
```

## 备注

圆体在小字号下笔画会糊在一起，如果你常用小屏，把浏览器缩放调到 110% 会好很多。
