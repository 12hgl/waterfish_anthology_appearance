# 护眼米

> 米色纸面配暖棕，长文连着读两小时眼睛不酸。

| | |
| --- | --- |
| 作者 | waterfish |
| 分类 | 阅读 |
| 哈希 | `04935e0b356d` |
| 写法 | 简单写法（键值对） |
| 适配 | 浅色为主 |

## 改了什么

| 键 / 手段 | 值 | 为什么 |

| `主色` | `#8C5A2B` | 暖棕，链接和图标都收在这支色里 |
| `副色` | `#B45309` | 页面底色会算出一点橙调淡彩 |
| `底色` | `#F7F1E6` | 米色纸面，比纯白低约 8% 亮度 |

## 安装

1. 打开水鱼文集 → 设置 → 外观 → 自定义主题
2. 把 [`04935e0b356d.js`](./04935e0b356d.js) 下载下来（右键另存为，或者从本页下方复制）
3. 点「选择 .js 主题文件」上传，列表里出现卡片即生效

```js
// 护眼米 —— 米色纸面 + 暖棕强调
主色: #8C5A2B
副色: #B45309
底色: #F7F1E6
```

## 备注

这套是文档里那个「护眼米色」配方的正式版本，加了底色让它在强光下也不发灰。
