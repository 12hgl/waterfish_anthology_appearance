# 白纸

> 把颜色全部抽掉，只剩下字和它周围的白。

| | |
| --- | --- |
| 作者 | waterfish |
| 分类 | 简洁 |
| 哈希 | `1d2d82e8c8ba` |
| 写法 | 简单写法（键值对） |
| 适配 | 浅色为主 |

## 改了什么

| 键 / 手段 | 值 | 为什么 |

| `主色` | `#2B2B2B` | 强调色退成墨灰，选中态靠灰度差而不是色相 |
| `副色` | `#8C8C8C` | 子菜单高亮条和页面淡彩一起变灰 |
| `底色` | `#FFFFFF` | 纯白，不掺任何色温 |
| `圆角` | `4` | 接近直角 |

## 安装

1. 打开水鱼文集 → 设置 → 外观 → 自定义主题
2. 把 [`1d2d82e8c8ba.js`](./1d2d82e8c8ba.js) 下载下来（右键另存为，或者从本页下方复制）
3. 点「选择 .js 主题文件」上传，列表里出现卡片即生效

```js
// 白纸 —— 只有黑白灰
主色: #2B2B2B
副色: #8C8C8C
底色: #FFFFFF
文字: #1C1C1C
圆角: 4
```

## 备注

这套几乎没有设计感，好处是换成任何字体都不违和。
