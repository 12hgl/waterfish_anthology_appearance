# 给水鱼文集换一套外观

水鱼文集是一个跑在自己 NAS 上的自托管阅读应用。界面外观以 `.js` 文件为单位：用户在
「设置 → 外观 → 自定义主题」里选一个文件上传，整套配色、字体、背景一起换掉。
社区写好的主题收在这个站点上，每套一个按内容哈希算出来的固定地址，内容不会变。

## 先看有哪些

- **结构化列表**（先用这个）：`{{ORIGIN}}/api/themes.json`
  里面有 `categories` 和 `themes` 两段。每套主题带 `hash`、`name`、`author`、`category`、
  `summary`、`mode`（`light` / `dark` / `both`）、`bytes`、`palette`、`src`、`url`。
- 人看的页面：`{{ORIGIN}}/library/`，分类是「推荐 / 简洁 / 阅读 / 深色 / 色彩 / 动效 / 字体」。
- 只看一类：`{{ORIGIN}}/library/c/<分类 id>/`。
- 单套详情：`{{ORIGIN}}/library/<hash>/`，同一路径下的 `<hash>.js` 就是主题文件本身。

## 怎么挑

1. 先问清口味再动手：白天用还是晚上用、要不要衬线字、看久了眼睛累不累。
   用户什么都没说的时候，给两套（一浅一深）让他挑，别替他决定。
2. `palette` 里的三个色值基本够判断气质：`paper` 是纸面、`ink` 是正文、`accent` 是强调色。
   不必把 js 全文读完。
3. `mode` 为 `light` 的主题在深色模式下会被应用强制回浅色。用户只说「一直开深色」的话，
   别推这种。
4. 「推荐」分类是维护者手动收的，不接受投稿；也不用建议用户往那里投。

## 怎么装

1. 下载 `src` 指向的 js，存成 `<主题名>.js`。例如
   `{{ORIGIN}}/library/7ae29bcdb75d/7ae29bcdb75d.js` 存成 `灯下.js`。
   **文件名就是主题名**：应用里显示的就是文件名。
2. 告诉用户：打开水鱼文集 → 左下角用户卡片 → 「自定义主题」→ 选择这个文件。
   选完立即生效并保存，没有确认按钮。
3. 顺手提醒限制：单文件 ≤ 64 KB（超出会被截断）、每人最多 20 个自定义主题、
   重名自动加 `(2)` 后缀。
4. 想换回来：同一个抽屉里选「纸墨」（内置默认），或悬停主题卡片点 ✕ 删掉。

## 不要做的事

- 不要改 js 内容再分发。地址按内容哈希算，改了就是另一套东西；真要改，本地另存个文件名。
- 不要替用户开投稿 issue。投稿要填作者、名称、简介，还要勾「这代码是我写的」——得本人来。
- 主题是别人写的代码，会在页面主世界跑。提醒用户只装来源可信的：站点的静态规则和 AI 复审
  只筛已知的危险写法，不等于安全审计。

## 想自己写一套

- 简单写法，一行一条，只写想改的：

  ```
  主色: #1F6C9F
  底色: #F4F7F9
  圆角: 12
  ```

  键：主色/副色/背景/字体/文字/底色/圆角（也认 accent/accent2/bg/font/ink/paper/radius）。
- 复杂写法：文件里定义 `function theme(api)`，可以 `api.setVar('--accent', '#7C5CFF')`、
  `api.css(...)` 注入样式、`api.icon(name, svg)` 换图标；`api.dark` 是当前是否深色。
- 写完从 `{{ORIGIN}}/submit/` 走投稿入口，issue 会被静态规则 + AI 复审先过一遍。
