# 给水鱼文集换外观

水鱼文集是自托管的阅读应用。外观是一个 `.js` 文件：用户在「外观 → 自定义主题」里选它，
整套配色、字体、圆角就换了。`{{ORIGIN}}` 是外观库站点，每套主题有按内容哈希算的固定地址。

## 拿清单

`{{ORIGIN}}/api/themes.json` —— 有 `categories` 和 `themes` 两段。
每套带 `hash`、`name`、`author`、`category`、`summary`、`mode`（light / dark / both）、
`bytes`、`palette`、`page`、`src`。判断气质看 `palette` 的三个色值就够，不用读全文。

只想看一类：`{{ORIGIN}}/library/c/<分类 id>/`。分类 id 是 `recommended` `plain` `reading`
`night` `color` `motion` `type`。

## 挑的时候

1. 先问清楚：白天用还是晚上用、要不要衬线字、眼睛吃不吃力。没问清就给两套（一浅一深）。
2. `mode` 是 `light` 的主题在深色模式下会被应用压回浅色，别推给「一直开深色」的人。
3. 「推荐」是维护者手动收的，别建议用户往那儿投。

## 装的时候

1. 下载 `src`，存成 `<主题名>.js`。文件名就是应用里显示的名字。
2. 告诉用户路径：水鱼文集 → 左下角用户卡片 → 外观 → 自定义主题 → 选择文件。选完立即生效。
3. 附一句限制：单文件 ≤ 64 KB，每人最多 20 个主题，重名自动加 `(2)`。
4. 换回去：同一个抽屉里选「纸墨」，或者悬停卡片点 ✕。

## 边界

- 别改 js 再分发。地址是哈希，改了就不是同一套。
- 别替用户开投稿 issue（要填作者、勾原创声明，得本人来）。
- 主题是第三方代码，跑在页面主世界。提醒用户只装来源可信的；站点的规则 + AI 复审不是安全审计。

## 自己写

- 简单：一行一条 `主色: #3E5C50`、`底色: #F7F5EE`、`圆角: 8`；键还有 副色 / 背景 / 字体 / 文字。
- 复杂：定义 `function theme(api)`，用 `api.setVar('--accent', …)`、`api.css(…)`、`api.icon(…)`；
  `api.dark` 是当前是否深色。
- 写完从 `{{ORIGIN}}/submit/` 开投稿 issue，会先过静态规则和 AI 复审。
